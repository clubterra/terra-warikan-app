# 割り勘計算アプリ（club Terra）

キャストが接客中に、質問に順番に答えるだけで「誰がいくら払うか」がすぐ分かる割り勘計算アプリです。

- ログイン不要、名前の入力も不要（「お客様1」「お客様2」でOK）
- 金額はすべて100円単位で、会計総額と支払合計が必ず一致するように計算します
- お客様の情報や金額はスマホの中だけで計算され、どこにも送信・保存されません
- インターネットに公開したあとは、アプリのインストールも不要です（ブラウザだけで使えます）

---

## 1. iPhoneで試す方法（かんたん手順）

### ① お店の管理者が、最初に1回だけ行うこと（GitHub Pagesの準備）

これは一度だけ行えば、あとはずっと同じURLで使えます。

1. パソコンのブラウザで、このリポジトリ（`clubterra/terra-warikan-app`）のGitHubページを開く
2. 上のほうにある「**Settings**」タブをクリック
3. 左側のメニューから「**Pages**」をクリック
4. 「Build and deployment」の「Source」を「**GitHub Actions**」に変更する
5. このブランチの内容が `main` ブランチに取り込まれる（マージされる）と、自動で公開されます
6. 1〜2分待つと、Pagesの画面に公開URLが表示されます（例：`https://clubterra.github.io/terra-warikan-app/`）

わからない場合は、詳しい人に「このリポジトリのGitHub Pagesを、GitHub Actionsで有効にしてください」と伝えてください。

### ② キャストが実際に使うとき

1. iPhoneの「**カメラ**」または「**メッセージ**」などで、上のURLを開くか、URLをブックマークしておく
2. Safari（オレンジ色の地球儀のアイコン）でそのURLを開く
3. 「はじめる」ボタンをタップして、質問に順番に答えるだけ

**もっと使いやすくする方法（ホーム画面に追加）**

1. SafariでアプリのURLを開く
2. 画面下の「共有」ボタン（四角から矢印が出ているアイコン）をタップ
3. 「**ホーム画面に追加**」をタップ
4. これで、アプリのアイコンのようにホーム画面から1タップで開けるようになります

## 2. お店のパソコンやスマホだけで試したい場合（社内テスト用）

GitHub Pagesを使わずに、その場ですぐ動作を確認したいときの方法です。

1. このフォルダをパソコンにダウンロードする
2. パソコンでターミナル（コマンド入力の画面）を開き、このフォルダに移動する
3. 次のコマンドを実行する

   ```
   npm run start
   ```

4. 表示されたアドレス（例：`http://localhost:8080`）を、パソコンとスマホの両方のブラウザで開く
   - スマホで見るときは、パソコンとスマホが同じWi-Fiに接続されている必要があります
   - パソコンの表示画面に出てくる「このパソコンのIPアドレス」を、スマホのSafariで代わりに入力してください（例：`http://192.168.1.20:8080`）

## 3. 使い方の流れ

1. 「お会計はいくら？」→ 税・サービス料込みの最終金額を入力
2. 「全部で何人？」→ 支払う人数を選ぶ
3. 「どうやって払う？」→ 次の3つから選ぶ
   - ① みんなで割り勘
   - ② 払う金額が決まっている人がいる
   - ③ みんな同じ額を払い、残りを1人が払う
4. 必要な質問（ボトル代・上乗せ額など）にだけ答える
5. 最後に「この金額をいただいてください」という結果画面が出る

「戻る」で前の画面に戻っても、入力した内容は消えません。
結果画面の「入力を修正」で、最初から入力し直せます。
「新しい会計」で、次のお客様の分をゼロから計算できます。

---

## 4. 計算のルール（お店のルールに合わせています）

- 支払額はすべて100円単位
- 会計総額と、全員の支払合計は必ず一致する
- 均等に割る部分は、差が最大100円になるように分ける
- 会計総額が100円単位でない場合は、自動で丸めずに「会計額を100円単位で確認してください」と表示して止まる
- ボトル代・上乗せ額・固定額は、それぞれ区別して計算する

---

## 5. 開発者向け情報

- 画面：`index.html` / `css/style.css` / `js/app.js`（Reactなどのビルド不要。ブラウザでそのまま動きます）
- 計算ロジック：`js/calc.js`（画面の見た目に関係ない、金額計算だけを行う部分）
- テスト：`test/calc.test.mjs`（仕様書にある検証例1〜6と、エラーになるべきケースを自動でチェック）

テストの実行方法：

```
npm test
```

`main` ブランチにマージされると、GitHub Actions が自動でテストを実行し、成功すればGitHub Pagesに公開します（`.github/workflows/deploy-pages.yml`）。
